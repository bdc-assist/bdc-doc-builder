# PIC-SURE guide

PIC-SURE lets you search phenotypic variables across every study on the platform without downloading any data.

## Open access

Open access PIC-SURE shows aggregate counts for any study. Counts below ten are obfuscated to protect participant privacy, and no individual-level data is ever returned.

## Authorized access

Authorized access PIC-SURE shows participant-level data for the studies you are approved for. Your approvals are checked every time you sign in, so a new approval appears within a day.

## Building a cohort

Start from the variable search box and type a concept such as "blood pressure" or "asthma". Each result lists the study, the variable name, its description and how many participants have a value. Select a variable to add it as a filter; categorical variables open a list of values to tick, and continuous variables open a range slider with the minimum and maximum observed values. Filters combine with AND by default, so every filter you add narrows the cohort. The participant count at the top of the page updates after each change, which makes it easy to see which filter removes most participants. To combine filters with OR, drag one filter onto another to make a group; groups can be nested two levels deep. When the cohort looks right, open the export tab and choose the variables to include in the dataset. The export keeps the filters with the dataset, so you can reopen the cohort later and change it. Exported datasets are written to the workspace you choose and named after the date and the cohort, for example cohort-2025-05-14. Large exports run in the background; you get an email when the dataset is ready, usually within ten minutes. If an export fails, the most common cause is a workspace without a billing project, so check the workspace settings first. Remember that authorized access exports only include studies you are approved for, even if open access showed counts for more studies, so the participant count can drop when you export. Save the cohort before you leave the page, because unsaved filters are cleared when you sign out.
