## Who can join

Anyone with an institutional login can create an account. Controlled data needs an approved data access request on top.

## How to join

Create an account, request access to the studies you need, then open your first workspace.

## Request access form

```form
url: https://platform.example/join/#request-access
fields:
  - name: full_name
    label: Full Name
    type: TEXT
    required: true
  - name: study
    label: Study you need
    type: DROPDOWN
    required: true
    choices: [Cohort A, Cohort B, Other]
```
